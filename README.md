# 급여 자동 정산 프로그램

엑셀 근태 파일을 업로드하면 근무자별 급여 정산서와 전체 급여 요약을 자동 계산하는 웹앱입니다.

## 주요 기능
- 엑셀 업로드: `.xlsx / .xls / .csv`
- 근무자별 시급 설정
- 수당 적용 ON/OFF
  - 주휴수당
  - 공휴일수당(일요일 제외)
  - 연장근무수당(1일 8시간 초과분)
  - 야간수당(개인별 야간 시작시각, 전체 야간 종료시각)
- 누락 기록 보정
  - 출퇴근 누락 시 기본 출근시각/기본 근무시간 자동 적용
  - 누락 근무 수동 추가
- 근무시간 수동 보정
  - 예: `3.2시간 -> 4시간`
- 결과 화면
  - 근무자별 정산서(날짜/출퇴근/주차별 급여)
  - 전체 급여 요약(전 직원 총계/세후 급여)

## 계산 기준
- 기본급: `정산시간 × 시급`
- 연장/야간/공휴일 수당: 해당 시간에 대해 `추가 0.5배`를 가산
- 공휴일수당: 사용자가 등록한 공휴일만 적용, 일요일은 제외
- 주휴수당: 주간 근무시간이 기준시간 이상일 때
  - `주휴시간 = (주간 근무시간 / 주간 근무일수) × 주휴 가중치`
  - `주휴수당 = 주휴시간 × 시급`
- 세후급여: `급여총계 - (급여총계 × 세율)`
- 관리자 누적 T: 2026년 8월까지는 기존 방식인 `월 총 근무시간 ÷ 8`로 계산
  - 2026년 9월부터 실제 근무기록을 날짜별로 합산해 `5시간 미만 = 0.5T`, `5시간 이상 = 1T`로 계산
  - 미래 관리자 배정표는 누적 T/P와 승진 계산에서 제외

## 로컬 실행
정적 파일 앱이라 별도 빌드가 필요 없습니다.

1. 이 폴더에서 간단한 정적 서버 실행
   - PowerShell 예시: `python -m http.server 5500`
2. 브라우저에서 `http://localhost:5500` 접속

## GitHub + Render 배포
1. GitHub 저장소 생성 후 현재 파일 업로드
2. Render에서 `New +` -> `Static Site`
3. GitHub 저장소 연결
4. 설정
   - Build Command: 비워두기
   - Publish Directory: `.`
5. 배포 완료 후 URL 접속

`render.yaml`도 포함되어 있어 Blueprint 배포도 가능합니다.

## 입력 즉시 저장 및 컴퓨터 간 공유

모든 변경은 브라우저에 즉시 보관됩니다. 공유 서버에 로그인하면 200ms 후 서버에도 저장하며,
다른 컴퓨터는 같은 서버 주소와 비밀번호로 연결하면 데이터를 불러옵니다.
화면 상단의 저장 상태로 로컬 저장과 공유 저장을 구분합니다.
연결이 끊기면 로컬 입력을 유지하고 재시도하며, 마지막 공유 상태를 기준으로 재접속 시 병합합니다.
서로 다른 항목의 동시 수정은 병합하고, 같은 항목의 충돌은 덮어쓰지 않고 표시합니다.
연결된 컴퓨터는 15초마다 다른 컴퓨터의 변경을 확인합니다. 급여 기록 배열처럼 하나의 목록을
동시에 수정하면 자동 병합하지 않고 충돌로 표시합니다.

현재 `render.yaml`은 기존 정적 사이트 설정입니다. 정적 사이트만으로는 공유 데이터를 저장할 수 없습니다.
`render-shared.yaml`을 이용해 **별도 Node 웹 서비스**를 배포하고 다음 환경변수를 설정해야 합니다.

- `DATABASE_URL`: 영구 PostgreSQL 데이터베이스 연결 주소. 브라우저나 GitHub에 넣지 않습니다.
- `SHARED_PASSWORD`: 관리자끼리 공유할 로그인 비밀번호. 브라우저 코드에 넣지 않습니다.
- `ALLOWED_ORIGIN`: 기존 사이트 주소 `https://payday-workday-calculator.onrender.com`.
- `DATABASE_SSL=true`: 외부 DB가 인증서 검증을 포함한 TLS 연결을 요구할 때 설정합니다.

배포 명령은 `npm ci`, 시작 명령은 `npm start`입니다. 서버 최초 시작 시 저장 테이블을 생성합니다.
기존 정적 사이트 상단의 ‘공유 저장 연결’에 **실제로 발급된 Node 서버 주소**와 비밀번호를 입력합니다.
새 서버도 동일한 앱 화면을 제공하므로 해당 주소로 직접 접속해 사용할 수도 있습니다.
비밀번호를 변경하면 기존 로그인은 만료됩니다. 최초 연결 시 서버에 데이터가 있으면 서버 내용을
불러오며, 연결 전 로컬 내용은 `payroll-before-shared-load` 키에 백업합니다.
충돌 시 먼저 기존 ‘전체 데이터 저장’으로 로컬 파일을 내보낸 다음 ‘공유 데이터 다시 불러오기’를 사용합니다.

DB를 자동 생성하거나 유료 자원을 신청하지 않습니다. Render의 무료 PostgreSQL은 생성 후 30일 만료되므로
장기 급여 데이터 저장소로 선택하면 안 됩니다. 영구 DB를 연결한 뒤 공유 저장을 운영해야 합니다.
참고: [Render 서비스 유형](https://render.com/docs/service-types), [무료 DB 만료 정책](https://render.com/docs/free).

## 2026년 11월 관리자 조건

제공된 설문 응답 중 11월 가능 시간과 ‘기타’의 근무 곤란 날짜/시간만 한 번 반영합니다.
권수현, 12월 응답, 희망 횟수·대체자·기타 운영 요청은 가져오지 않습니다.
장채민의 월·화·수 1T는 최우선 고정이며 11/2와 11/23은 근무 불가입니다.
저녁 2T와 늦은 출근/이른 퇴근 제한은 해당 근무자의 실제 배정 시각에 반영합니다.
주간 조건은 선택한 배정 월별로 저장하고, 기존 월간 배정 결과를 자동 재생성하지 않습니다.
수정한 조건으로 캘린더를 생성하려면 해당 월에서 자동 배정을 실행합니다.

검증: `npm test`. 로컬 정적 화면 확인은 `npm run dev`.
